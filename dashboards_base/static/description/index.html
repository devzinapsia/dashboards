Dashboards

Base app and shared infrastructure for executive dashboards

This module creates the "Dashboards" app and the reusable building blocks that every dashboard concept module (Collection, Invoicing, Purchases, ...) relies on:

  • The "Dashboards" app menu, with its "Boards" and "Configuration" submenus ready for concept modules to hang their own entries on.
  • A "Dashboards" security category, so every concept module's access groups are grouped together in Settings > Users & Companies > Permissions.
  • Reusable OWL components: a KPI card and a Chart.js chart wrapper, both theme-aware (light/dark).
  • A drill-down helper (JS and Python) to open a filtered window action from any KPI card.

This module has no business indicators of its own — it is pure infrastructure for other dashboard modules to build on.
